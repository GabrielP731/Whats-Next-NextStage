This is a place to store any files that were downloaded in 
the development of "What's Next".



!!DISCLAIMER!!
When Importing, create these two things:

    1) Separate Directories

    Every creation that has been downloaded must get its 
    own sub-directory.
    
    Do not dump your junk here without organizing it.
    
    I'd personally create a parent directory that has the 
    name of each artist. This has helped me keep track of 
    all creators/files that must be given credit. 

    An example directory would look like

    "../../external_assets/imports/Kevin Macleod/
        Investigations/[YOUR FILES HERE]"

    For Kevin Macleod's song named "Investigations"

    2) Artist Credits

    GIT already doesn't push directories that do not have 
    any files being tracked within them.

    This is why most of the sub-directories in 
    'external_assets' have a file in them named 
    
    "README.md"
    

    I recommend you enter any artist information in these 
    READ-ME files as you download them from the web. 
    
    Their 
        name, 
        website,  
        licensing information

    should be included in the READ-ME.
