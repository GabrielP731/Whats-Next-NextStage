This is a directory to store all animated-graphics for
use in the development of "What's Next"


Note: I suggest each asset be given its own subdirectory
to bundle together all the individual frame files
(similar to what we used in 'Workshop 1' in ITSC 4230/5230)

I would also suggest giving each subdirectory a general
prefix that indicates its purpose

For example: you've probably seen the directory
"../animated/BG_valleygrass" which has the "BG_" prefix.
The prefix "BG" stands for "Background"

I do not have a list of all the prefixes that will be made,
but try to follow the prefix-conventions that form as this 
folder becomes more populated.
